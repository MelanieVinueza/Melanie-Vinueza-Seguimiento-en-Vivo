La aplicación necesita configuración

Esta página no funciona con Live Server: utiliza React y debe iniciarse con Vite.

Abre una terminal en la carpeta del proyecto y ejecuta:

npm install
npm run dev

Completa la configuración pública de Firebase en el archivo .env, siguiendo los pasos del README.md. El mapa OpenStreetMap no necesita clave.
